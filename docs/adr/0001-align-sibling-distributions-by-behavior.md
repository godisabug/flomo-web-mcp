# Align sibling distributions by behavior

Keep `flomo-web-cli` and `flomo-web-mcp` as separate distribution repositories while treating CLI tag `v0.1.6` at commit `e9711de` as this release's Shared Core Baseline. Port shared flomo behavior into the MCP adapter and protect parity by recording the source baseline and carrying equivalent behavior-focused test cases; do not use cross-repository source diffs, introduce a shared package, or create a monorepo in this release, because those approaches either compare adapter-specific structure or expand a compatibility update into a repository and release-system migration. Shared Core releases converge on the same package version across both distributions, while adapter-only releases may advance independently until the next Shared Core release reunifies their versions.
